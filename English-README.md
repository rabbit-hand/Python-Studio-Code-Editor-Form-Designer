# Python Studio Editor User Manual

Python Studio Editor is a lightweight and simple Python GUI code editor and Tkinter form designer designed for beginners, learners, and hobbyists.

It allows you to create desktop applications and learn Python/Tkinter intuitively without complex environment setup.

## 1. Key Features

### Simple & Lightweight Code Editor

- Syntax highlighting (color-coded keywords, strings, and comments)
- Line number display
- Font size adjustment
- Light/dark theme switching
- Search and replace functions
- Automated code formatting via PEP8 (`autopep8`)

### Beginner Project Catalog

- Comes standard with practical sample codes such as:
  - calculators
  - rock-paper-scissors
  - ToDo lists
  - file managers
  - JSON editors
  - calendars
- Instantly load samples into the editor with a single click

### Intuitive Tkinter Form Designer

- Drag-and-drop style placement of GUI widgets such as buttons and labels
- Automatically generates executable Python/Tkinter code from your visual layouts

### Hotkey & Button Creator

- Automatically generates task automation code for:
  - opening URLs
  - launching applications
  - sending keystrokes
- Supports custom shortcuts or button actions
- Supports system tray resident functionality

## 2. System Requirements

- **Supported OS:** Windows 10 / 11
- **Python:** Python 3.8 or later
- **Dependencies:** Python standard libraries (`tkinter`, `ctypes`, `json`, `subprocess`, etc.)

> **Note:** External libraries such as `autopep8`, `pystray`, `pillow`, and `keyboard` are used for certain extended features.

## 3. Installation & Startup

1. Download the relevant `.pyw` or `.py` file  
   (for example: `Python Studio Editor v0.2.4 English.pyw`) from the repository.

2. Double-click the file in an environment where Python is installed.

3. If running from a terminal or command prompt, execute the following command:

```bash
python "Python Studio Editor v0.2.4 English.pyw"
```

## 4. Basic Usage

### Code Editor

- Write your Python code directly in the main editor workspace.
- Perform file operations such as:
  - **Save**
  - **Save As**
  - **Open**
- Use keyboard shortcuts to:
  - launch the search/replace dialogs
  - execute code formatting

### Beginner Project Catalog

- Open the project list to browse sample programs categorized by type.
- Select a project and click **Load code into editor** to instantly transfer executable code to your workspace.

### Tkinter Form Designer

- Select the form creation tab to launch the visual designer.
- Add and arrange widgets such as:
  - buttons
  - labels
  - text input fields
- Adjust properties like:
  - text
  - dimensions
- Click the **Generate Code** button to automatically output the Python code corresponding to your layout.

### Hotkey & Button Creator

- Assign specific actions such as:
  - opening web pages
  - launching files
- Use your desired key combinations (for example: `Alt + A`) or button clicks.
- Export custom utility code designed to run persistently in the system tray once configured.
