# 📘 Python Studio Editor – README  
GUIフォームデザイナ & Pythonコードエディタ  
（ドローン制御・ホットキー・外部機器連携対応）

---

## 🏷️ 概要

**Python Studio Editor** は、  
**GUIフォームデザイナ + Pythonコードエディタ + プロジェクト管理 + 実行環境 + 拡張ツール**  
を 1 ファイルで提供する統合型ミニ IDE です。

Visual Basic / Delphi のようなドラッグ配置 GUI と Python コード編集を統合し、  
さらにホットキー設定、仮想環境管理、外部デバイス制御（ドローン等）まで扱える柔軟な設計になっています。

---

## ✨ 主な機能

---

## 🎨 GUI フォームデザイナ

- ドラッグ＆ドロップでウィジェット配置  
- リサイズ・移動・整列・スナップ  
- プロパティ編集（位置 / サイズ / 色 / フォント / テキスト / イベント名）  
- イベントコード自動生成  
- GUI プレビュー  
- ウィジェット階層ツリー表示  
- 複数フォーム管理  

---

## ✏️ Python コードエディタ

- シンタックスハイライト（Pygments）  
- Undo / Redo  
- 検索・置換  
- 自動インデント  
- autopep8 によるコード整形  
- 複数ファイル編集  
- フォーム生成コードとの連携  
- 簡易コード補完  

---

## 🗂️ プロジェクト管理

- プロジェクトフォルダ自動生成  
- フォーム / コード / 設定ファイル保存  
- 複数プロジェクト切り替え  
- テンプレートプロジェクト作成  

---

## 🧪 実行・テスト機能

- ワンクリック実行  
- 仮想環境（venv）で安全実行  
- タイムアウト実行（test_timeout_seconds）  
- ログ出力ウィンドウ  
- エラー表示（スタックトレース）  

---

## 🧰 仮想環境（venv）管理

- 専用仮想環境の自動作成  
- 必要ライブラリの自動インストール  
  - pillow  
  - pywin32  
  - pygments  
  - autopep8  
  - tkinter  
- Python パス管理  
- pip 自動アップグレード  

---

## 🎛️ ホットキービルダー（Hotkey Builder）

- エディタ操作ショートカット設定  
- フォームデザイナ操作ショートカット設定  
- ホットキー設定ファイル保存  
- 設定の読み込み・適用  

---

## 🎨 テーマ・UI カスタマイズ

- ライト / ダークテーマ  
- フォントサイズ変更  
- ウィンドウサイズ記憶  
- UI 設定ファイル保存  

---

## 📡 外部デバイス制御（ドローン・ロボット・偽装機器など）

Python Studio Editor は、  
**外部 API やライブラリを使ったデバイス制御コードの開発にも対応** しています。

### 対応可能な制御例

- ドローン制御  
  - DJI / Tello / MAVLink  
  - 離陸 / 着陸 / 前進 / 停止などの GUI ボタン操作  
- ロボットアーム制御  
- 自律ロボット・偽装機器の制御  
- センサー読み取り（温度 / 距離 / GPS）  
- ネットワーク制御（UDP / TCP / WebSocket）  

フォームデザイナで作った GUI に  
「離陸」「着陸」「前進」「停止」などのボタンを配置し、  
Python コード側で API を呼び出すことで、  
**GUI 付きドローンコントローラ** を作ることができます。

## 🔌 外部連携・拡張機能

- Web API 呼び出し

- 設定ファイル（JSON）管理  

---

## 📥 インストール方法

1. Python 3.x をインストール  
2. `install_python.bat` を実行  
3. 必要ライブラリが自動インストール  
4. 仮想環境がデスクトップに作成  
5. `Python Studio Editor English.pyw` を起動  

---

## 📚 使い方の流れ

1. 新規プロジェクト作成  
2. フォームデザイナで GUI を作成  
3. イベントコードを記述  
4. プロジェクト保存  
5. 実行して動作確認
