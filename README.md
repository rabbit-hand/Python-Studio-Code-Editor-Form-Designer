# Python Studio Editor v0.2

Python Studio Editor は、PythonコードエディターとGUIフォームデザイナーを統合した統合開発環境（IDE）です。

Visual Basic や Delphi のような RAD（Rapid Application Development）ツールに着想を得て開発されており、ドラッグ＆ドロップによるフォーム設計と Python コード編集を1つの環境で行うことができます。

初心者から経験者まで、効率的に Python GUI アプリケーションを開発できることを目的としています。

---

## 主な機能

### GUIフォームデザイナー

- ドラッグ＆ドロップによるフォーム設計
- ボタン、ラベル、入力ボックスなどの配置
- コントロールの移動・サイズ変更
- プロパティ編集
- オブジェクトツリー表示
- フォームプレビュー
- イベントコード自動生成
- 複数フォーム対応

### Pythonコードエディター

- Python構文ハイライト
- Undo / Redo
- 検索・置換
- 自動インデント
- コード整形
- 複数ファイル編集
- フォームとコードの連携編集
- ショートカットキー対応

### プロジェクト管理

- プロジェクト作成
- プロジェクト保存
- フォーム保存
- 設定管理
- ファイル管理
- フォルダー管理

### 実行・デバッグ

- ワンクリック実行
- 出力ログ表示
- エラー表示
- スタックトレース表示
- テスト実行支援

### カスタマイズ

- ライトテーマ
- ダークテーマ
- フォントサイズ変更
- ウィンドウ状態保存
- ショートカットキー設定

## 動作環境

### 対応OS

- Windows 10
- Windows 11

### 必要環境

- Python 3.x

### 推奨ライブラリ

```bash
pip install pillow pygments autopep8 pywin32
```

## 起動方法

```bash
python "Python Studio Editor v0.2 English.pyw"
```

または `.pyw` ファイルをダブルクリックしてください。
