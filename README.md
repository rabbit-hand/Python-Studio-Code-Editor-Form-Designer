# 📘 Python Studio 説明書（日本語版）

## 🐍 はじめに
Python Studio は、Python の GUI アプリケーションを簡単に作成できる統合環境です。
フォームデザイナー、コードエディタ、自動整形、仮想環境管理、ワンクリック実行を
すべて 1 つの `.pyw` ファイルで提供します。

初心者でも GUI を作れ、上級者はコードを直接編集できます。

---

## 💡 なぜ Python Studio を作ったのか
Python は世界中で愛されている素晴らしい言語ですが、
初心者が GUI アプリケーションを作ろうとすると、いきなり高い壁にぶつかることがあります。

「どこから始めればいいのか分からない」
「コードだけで画面を作るのは難しい」
「専門用語が多すぎる」
「インデントや記号のルールが理解できない」

こうした壁が一度に押し寄せると、論理構造がまだ身についていない初心者は
ただ滑り落ちるしかなく、挫折してしまうことが多いのです。

Scratch から Python に移行する時も同じで、
英語の命令・記号・インデント・専門用語など、
“言語の壁” が一気に高くなる瞬間があります。

本来なら、日本語プログラミング言語を挟んで段階的に学ぶという選択肢もあります。
しかし、多くの人は「職業プログラミングを学ぶなら日本語言語は必要ない」と言います。
その結果、準備ができていないまま、いきなり大きな壁に挑むことになり、
挫折してしまう初心者が後を絶ちません。

私は、それがずっと危険だと思っていました。

だからこそ、
「たとえ挫折しても、日常で使えるツールが残る環境」  
を作りたいと思ったのです。

Python Studio は、
初心者が壁にぶつかっても、
「自分で GUI を作れた」という成功体験が残り、
将来また挑戦したくなる“足場”になるように設計しました。

もし AI がなかったら、このツールは絶対に作れませんでした。
でも、AI と協力することで、
初心者が泣かずに済む環境を作れるなら、それは大きな意味があると思っています。

Python Studio は、
「いきなり大きな壁に登らなくてもいい」
「まずは楽しく作れるところから始めよう」  
という案内のために作りました。

---

## 🚀 起動方法
1. Python 3.x をインストール
2. `Python Studio Editor English.pyw` をダブルクリック
3. すぐに起動します（追加のインストールは不要）

---

## 🖥 画面構成

### 🎨 フォームデザイナー
GUI をドラッグ＆ドロップで作成できます。

- ウィジェットの配置
- サイズ変更
- 移動
- プロパティ編集
- イベント設定
- プレビュー表示

### ✏️ コードエディタ
- シンタックスハイライト
- 自動インデント
- autopep8 による整形
- 保存・読み込み
- プロジェクト管理

### ⚙️ プロパティパネル
- テキスト
- 色
- サイズ
- 配置
- イベント名

---

## 📂 プロジェクトの作成
1. 新規プロジェクトを作成
2. GUI を配置
3. 必要ならコード編集
4. 保存するとプロジェクトフォルダが生成されます

---

## 🔧 仮想環境（venv）
Python Studio はプロジェクトごとに自動で venv を作成します。

- venv の自動生成
- autopep8 の自動インストール
- venv 内で安全に実行

---

## ▶️ 実行方法
- 「Run」ボタンで起動
- 標準出力
- エラー表示
- タイムアウト保護

---

## ⚠️ 注意点
- Windows 専用
- Tkinter 専用
- 大規模 GUI は Canvas が重くなる場合あり

---

## ❓ よくある質問（FAQ）

**Q. Python は必要ですか？**  
A. はい、Python 3.x が必要です。

**Q. 追加のインストールは必要ですか？**  
A. いいえ。ファイルをダブルクリックするだけで起動します。

**Q. PyQt や wxPython には対応していますか？**  
A. 現時点では Tkinter のみ対応しています。
