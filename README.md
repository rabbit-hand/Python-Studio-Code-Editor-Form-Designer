
# Python Studio Editor (v0.2.3) 取扱説明書

## 1. 概要

「Python Studio Editor」は、Tkinterを使用して構築されたWindows向けのPythonコードエディター兼開発支援ツールです。Pythonスクリプトの作成・編集・実行に加え、初心者向けの豊富なサンプルコードの閲覧や、ホットキー・ボタン作成ユーティリティを搭載しています。

---

## 2. 主な機能と使い方

### ① 基本的なコード編集機能

* **ファイル操作**:
* **新規作成 / 開く / 上書き保存 / 名前を付けて保存**: `.py` および `.pyw` ファイルに対応しています。
* **未保存の変更検知**: 変更がある場合はステータスバーや終了時の確認ダイアログでお知らせします。


* **エディター表示**:
* **シンタックスハイライト**: Pythonのキーワード、文字列、コメントを視覚的に強調表示します。
* **行番号とステータス表示**: 現在の行・列・文字数、作業中のファイル名を表示します。
* **テーマ切り替え**: ダークモード（デフォルト）とライトモードをワンクリックで切替可能です。
* **フォントサイズ調整**: エディターの文字サイズを変更できます。


* **検索と置換**:
* キーワード検索、次を検索、置換、一括置換機能（`Ctrl+F` など）に対応しています。



### ② コードフォーマット & 実行（仮想環境）

* **自動フォーマット**: `autopep8` モジュールを介してコードを整形します。
* **仮想環境（venv）の自動構築**:
* デスクトップ上に専用の仮想環境フォルダ（`Pythonエディター_仮想環境`）を自動作成します。
* 安全な独立環境でPythonスクリプトの実行および動作テストが行えます。



### ③ 初心者向け作品カタログ（サンプル集）

* ミニアプリ（電卓、じゃんけん、数当てゲーム、タイマーなど）
* 実用ツール（ToDoリスト、メモ帳、パスワード生成器、ファイル名一括変更、CSV集計など）
* 応用・連携機能（Webタイトル取得、Open-Meteo天気取得、Discord Webhook送信、LINE Messaging API送信など）
* ※選んだサンプルコードはワンクリックでエディターへ読み込むことができ、必要な外部モジュールの自動インポート補助機能も備えています。

### ④ ホットキー・ボタン作成（Hotkey Builder）

* キーボードショートカット（例: `Alt+A`）やボタン操作に対して、指定したアクション（URLを開く、アプリ/ファイルの起動、キー送信、コマンド実行など）を割り当てたカスタムツール（タスクトレイアプリ）を作成・コード生成できます。

---

## 3. 動作環境とセットアップ

* **OS**: Windows（タスクトレイやWindows固有APIを使用する機能があるため）
* **必須環境**: Python 3.x
* **推奨パッケージ（一部機能で使用）**:
* `autopep8`（コード整形用）
* `pystray`, `Pillow`, `keyboard`（タスクトレイおよび高度なホットキー機能用）
