# 📘 Python Studio 説明書（日本語版）

## 🐍 はじめに
Python Studio は、Python の GUI アプリケーションを簡単に作成できる統合環境です。
フォームデザイナー、コードエディタ、自動整形、仮想環境管理、ワンクリック実行を
すべて 1 つの `.pyw` ファイルで提供します。

初心者でも GUI を作れ、上級者はコードを直接編集できます。

---

## 💡 なぜ Python Studio を作ったのか
Python は世界中で愛されている素晴らしい言語ですが、
GUI アプリケーションを作るとき、初心者には少し難しく感じられることがあります。

「どこから始めればいいのか分からない」
「コードだけで画面を作るのは大変」
そんな理由で挫折してしまう人もいます。

私は、プログラミングを始めたばかりの人が
“難しすぎて泣いてしまう” そんな経験を減らしたいと思いました。

みんながプロのプログラマーになる必要はありません。
でも、日常で使える小さなツールを自分で作れるだけで、
それだけで大きな価値があります。

初心者が安心して学べるように、まずは「楽しく作れる環境」を提供したい。
その気持ちから Python Studio を作りました。

---

## 🚀 起動方法
1. Python 3.x をインストール
2. `Python Studio Editor English.pyw` をダブルクリック
3. すぐに起動します（追加のインストールは不要）

---

## 🖥 画面構成

### 🎨 フォームデザイナー
GUI をドラッグ＆ドロップで作成できます。

- ウィジェットの配置
- サイズ変更
- 移動
- プロパティ編集
- イベント設定
- プレビュー表示

### ✏️ コードエディタ
- シンタックスハイライト
- 自動インデント
- autopep8 による整形
- 保存・読み込み
- プロジェクト管理

### ⚙️ プロパティパネル
- テキスト
- 色
- サイズ
- 配置
- イベント名

---

## 📂 プロジェクトの作成
1. 新規プロジェクトを作成
2. GUI を配置
3. 必要ならコード編集
4. 保存するとプロジェクトフォルダが生成されます

---

## 🔧 仮想環境（venv）
Python Studio はプロジェクトごとに自動で venv を作成します。

- venv の自動生成
- autopep8 の自動インストール
- venv 内で安全に実行

---

## ▶️ 実行方法
- 「Run」ボタンで起動
- 標準出力
- エラー表示
- タイムアウト保護

---

## ⚠️ 注意点
- Windows 専用
- Tkinter 専用
- 大規模 GUI は Canvas が重くなる場合あり

---

## ❓ よくある質問（FAQ）

**Q. Python は必要ですか？**  
A. はい、Python 3.x が必要です。

**Q. 追加のインストールは必要ですか？**  
A. いいえ。ファイルをダブルクリックするだけで起動します。

**Q. PyQt や wxPython には対応していますか？**  
A. 現時点では Tkinter のみ対応しています。
