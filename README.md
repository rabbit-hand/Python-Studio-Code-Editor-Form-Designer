**Python Studio – Code Editor & Form Designer**  
取扱説明書

### 1. 概要
Python Studioは、Pythonのコード編集とビジュアルなフォーム（ウィンドウ）デザインを一体化した開発ツールです。  
コードを書きながら、ドラッグ＆ドロップでGUIを設計できます。

### 2. 主な機能
- **コードエディタ**  
  構文ハイライト、行番号表示、自動インデント、コード補完、複数タブ編集
- **フォームデザイナー**  
  コントロール（ボタン、テキストボックス、ラベルなど）をドラッグ＆ドロップで配置
- **イベント生成**  
  コントロールをダブルクリックすると、対応するイベント関数が自動生成される
- **実行・デバッグ**  
  作成したプログラムをその場で実行可能
- **プロジェクト管理**  
  ファイルの作成・保存・整理

### 3. 基本的な使い方

#### 3.1 新規プロジェクトの作成
1. メニューから「新規」→「プロジェクト」または「新規フォーム」を選択
2. プロジェクト名を入力して作成

#### 3.2 フォームのデザイン
1. ツールボックスからコントロールを選択
2. フォーム上にドラッグ＆ドロップして配置
3. プロパティウィンドウでサイズ・位置・テキストなどを調整
4. 必要に応じてオブジェクトツリーで階層を確認

#### 3.3 イベントの追加
1. ボタンなどのコントロールをダブルクリック
2. コードエディタにイベント関数が自動生成される
3. 関数内に処理を記述

#### 3.4 コードの編集
- フォームとコードを同時に表示・編集可能
- 通常のPythonコードと同様に記述

#### 3.5 実行
- 「実行」ボタンまたはショートカットキーでプログラムを起動
- エラーが出た場合はメッセージを確認して修正

#### 3.6 保存
- 「ファイル」→「保存」でプロジェクトを保存
- 必要に応じて実行ファイルとして出力

### 4. 画面構成（一般的なレイアウト）
- 左側：ツールボックス（コントロール一覧）
- 中央：フォームデザイン画面 / コードエディタ
- 右側：プロパティウィンドウ
- 下部：出力ウィンドウ / コンソール
- 上部：メニューバー・ツールバー

### 5. 基本操作のポイント
- コントロールの選択：クリック
- 複数選択：Ctrlキーを押しながらクリック
- 移動・リサイズ：マウスでドラッグ
- 削除：Deleteキー
- コピー＆ペースト：Ctrl+C / Ctrl+V

### 6. 注意事項
- 保存をこまめに行うこと
- 実行前に構文エラーがないか確認すること
- 大きなプロジェクトでは定期的にバックアップを取ること
