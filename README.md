# 📘 Python Studio 説明書（日本語版）

## 🐍 はじめに
Python Studio は、Python の GUI アプリケーションを簡単に作成できる統合環境です。
フォームデザイナー、コードエディタ、自動整形、仮想環境管理、ワンクリック実行を
すべて 1 つの `.pyw` ファイルで提供します。

初心者でも GUI を作れ、上級者はコードを直接編集できます。

---

## 💡 なぜ Python Studio を作ったのか

Python は世界中で愛されている素晴らしい言語ですが、初心者がいきなり Python に挑むと、思わぬところでつまずくことがあります。

実際に、チャットで小学生と話したときのことです。  
その子は「ボク、スクラッチやってるからプログラム大丈夫だよ」と言っていました。  
そこで私は「コメントの記号って分かる？」と聞いてみました。  
すると返ってきた答えは「何それ？」でした。

この経験から、スクラッチから Python に移るときの壁の高さを強く感じました。

Python では、コメント記号、インデント、記号の意味、英語の専門用語、論理構造など、さまざまな壁が一度に押し寄せます。  
論理構造がまだ身についていない初心者にとって、これはただ滑り落ちるだけの崖のようなものです。

多くの人は「職業プログラミングを学ぶなら日本語プログラミング言語は必要ない」と言います。  
しかし、準備ができていないまま大きな壁に挑めば、挫折するのは当然です。

私は、それがずっと危険だと思っていました。

いきなり Python の壁に登らなくてもいい。  
まずは楽しく作れる環境が必要だと考えました。

もし途中で挫折しても、自分で GUI を作れたという成功体験が残るなら、それは将来の大きな財産になります。

Python Studio は、初心者が泣かずに済むように、そしていつかまた挑戦したくなるように、足場としての役割を持たせたくて作りました。

AI がなかったら絶対に作れませんでしたが、AI と協力することで初心者が安心して学べる環境を作れるなら、それは大きな意味があると思っています。

---

## 🚀 起動方法
1. Python 3.x をインストール
2. `Python Studio Editor English.pyw` をダブルクリック
3. すぐに起動します（追加のインストールは不要）

---

## 🖥 画面構成

### 🎨 フォームデザイナー
GUI をドラッグ＆ドロップで作成できます。

- ウィジェットの配置
- サイズ変更
- 移動
- プロパティ編集
- イベント設定
- プレビュー表示

### ✏️ コードエディタ
- シンタックスハイライト
- 自動インデント
- autopep8 による整形
- 保存・読み込み
- プロジェクト管理

### ⚙️ プロパティパネル
- テキスト
- 色
- サイズ
- 配置
- イベント名

---

## 📂 プロジェクトの作成
1. 新規プロジェクトを作成
2. GUI を配置
3. 必要ならコード編集
4. 保存するとプロジェクトフォルダが生成されます

---

## 🔧 仮想環境（venv）
Python Studio はプロジェクトごとに自動で venv を作成します。

- venv の自動生成
- autopep8 の自動インストール
- venv 内で安全に実行

---

## ▶️ 実行方法
- 「Run」ボタンで起動
- 標準出力
- エラー表示
- タイムアウト保護

---

## ⚠️ 注意点
- Windows 専用
- Tkinter 専用
- 大規模 GUI は Canvas が重くなる場合あり

---

## ❓ よくある質問（FAQ）

**Q. Python は必要ですか？**  
A. はい、Python 3.x が必要です。

**Q. 追加のインストールは必要ですか？**  
A. いいえ。ファイルをダブルクリックするだけで起動します。

**Q. PyQt や wxPython には対応していますか？**  
A. 現時点では Tkinter のみ対応しています。
